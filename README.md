# 侧边抽屉 SideDrawer

一个轻量级 Windows 桌面侧边抽屉：鼠标滑到屏幕左边缘呼出，半屏宽、**原生 Win11/Win10 DWM 实时模糊玻璃**质感，集成桌面快捷方式管理、系统性能监控与独立悬浮音乐面板。

原生 **C# + WPF** 手写实现，**零第三方依赖**（无 NuGet、无外部 DLL、无 XAML 文件），用系统自带的 `csc.exe` 即可编译为单个约 240 KB 的可执行文件。

---

## 核心特性

### 1. 原生实时模糊玻璃（v1.2 重构）
- **零截屏实时模糊**：基于 Windows 原生 DWM `ACCENT_ENABLE_BLURBEHIND` + 硬件圆角（`DWMWCP_ROUND`），支持 Wallpaper Engine 等动态壁纸与后台窗口实时透出模糊，不再使用静态截屏底图。
- **双模式即时切换**：主侧边栏支持右键开关「模糊玻璃」，随时在**实时模糊玻璃**（无暗角、清爽通透）与**通透液态玻璃**（保留四周暗角）之间原地切换。
- **常驻模糊音乐面板**：右上角音乐面板升级为独立 DWM 实时模糊窗口，无四角阴影伪影。

### 2. 高刷丝滑体验与锐利渲染（v1.2）
- **高刷适配**：自动检测显示器原生刷新率（60Hz / 144Hz / 180Hz / 240Hz 等）。
- **独立高精度滑动动画**：侧边栏与音乐面板展开/收回由独立高精度时钟同步驱动，高刷屏实测可达 160~170fps，告别闪现与空框。
- **像素对齐阻尼滚动**：帧率无关平滑滚轮滚动，静止时自动按物理像素对齐，不发虚。
- **高 DPI 锐利直出**：图标与文字原生矢量/高清直出渲染，高缩放比下清晰锐利。

### 3. FPS 游戏视角转动防误触（v1.2）
- 左侧边缘书签支持三级防误触策略（右键菜单 →「防误触」）：
  - **智能防误触（默认）**：自动识别鼠标锁定/隐藏（`GetCursorInfo` + `GetClipCursor`）、按住鼠标按键（开火/拖拽）、Raw Input 游戏光标静止，并区分桌面（60ms）与非桌面（220ms）悬停延时。
  - **仅桌面触发**：仅当桌面或任务栏处于前台时响应左边缘呼出。
  - **关闭**：保持原始左边缘即触即弹。
- 展开/收回动画期间自动防误点，避免手速过快误启动图标。

### 4. 快捷方式、性能与音乐
- **图标网格与分类胶囊**：自动扫描当前用户桌面 + 公共桌面快捷方式，归类为 `日常 / 工具 / 启动器 / 游戏`；支持展开/折叠、新建、重命名、删除、拖拽归组、右键手动添加（支持多选）、自定义图标（`icons/快捷方式名.png`）。
- **系统状态卡片**：实时显示 CPU（从注册表读取真实型号）、GPU（自动识别单/双显卡，后台线程批量采样零卡顿）、内存占用。
- **音乐面板**：通过 Windows SMTC 自动读取网易云、QQ 音乐、Apple Music、Spotify、浏览器等正在播放的媒体，支持封面、切歌、暂停/播放与多源同步歌词（本地 `lyrics/*.lrc` → 网易云 → QQ 音乐 → lrclib）。
- **分辨率自适应与细节开关**：性能卡、分类胶囊、时钟、音乐面板按屏幕高度等比缩放；支持开机自启、时钟配色、收起按钮深浅色、点击面板外收回、全屏游戏自动隐藏。

## 快速使用（免编译）

直接从 GitHub Releases 下载便携包 `侧边抽屉-v1.2.zip` 解压即可：

1. 双击 `侧边抽屉.exe` 启动（免安装、免管理员、默认不写注册表）
2. 鼠标移到屏幕**最左侧垂直居中**滑出书签 → 点击展开，或直接按 `Ctrl + Alt + D`
3. 右键面板空白处打开设置菜单

首次运行会在 exe 同目录生成 `drawer.json` 配置文件，可直接编辑或通过右键菜单修改。

## 从源码构建

### 环境要求
- Windows 10 1809+ / Windows 11（64 位）
- .NET Framework 4.x（系统自带，无需额外安装）

### 编译命令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

产物位于 `bin\SideDrawer.exe`（单文件，约 240 KB）。

`build.ps1` 直接调用系统自带编译器：

```text
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

并引用 WPF 程序集与 `C:\Windows\System32\WinMetadata\*.winmd`（用于 WinRT SMTC 媒体控制）。

## 目录结构

```text
Program.cs          主程序：DWM 主窗口、分类网格、平滑滚动、防误触配置、性能监控、菜单
MusicPanel.cs       独立 DWM 实时模糊音乐面板：SMTC 读取、封面缓存、多源歌词
Glass.cs            原生 DWM 实时模糊（BlurBehind/圆角/高精度滑动时钟）与图形辅助
OrnateFrame.cs      樱花线稿包边（矢量几何绘制）
EdgeTab.cs          左边缘书签窗口（含 FPS 智能防误触状态机）
ScreenUtil.cs       多 DPI 工作区与屏幕几何计算
InputBox.cs         自绘输入框对话框（新建分类、重命名）
SpectrumPanel.cs    音频频谱组件（实验性，默认不启用）
SpectrumWindow.cs
AssemblyInfo.cs     程序集版本与元信息
build.ps1           一键编译脚本（csc.exe）
app.manifest        Per-Monitor DPI 感知清单
app.ico             应用图标
```

## 隐私说明

- 程序**不上传任何个人数据**；`drawer.json` 仅保存在本地 exe 同目录。
- 仅音乐面板在播放歌曲时访问公开歌词接口（网易云 / QQ 音乐 / `lrclib.net`），且只发送歌名与歌手信息。
- 仓库中不含任何 API Key、Token 或个人桌面配置；`drawer.json`、`log.txt`、`lyrics/` 均已加入 `.gitignore`。
